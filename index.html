Rover controls are demo mode here — not connected to a physical rover. In the field deployment these buttons call the Raspberry Pi's Flask API, which relays commands to the ESP32 over serial; a watchdog on the ESP32 auto-stops the rover if the link drops.
SMS emergency alerts
Planned · Phase 2
How it will work
Runs on a GSM module (2G cellular) attached to the Pi — independent of Wi-Fi or internet, so it reaches the farmer even outside the dashboard's Wi-Fi range. Triggers are calculated on-device from local sensor thresholds; no weather API call is needed to send an alert.
Precision sprayingtargeted intervention, not blanket spraying
Closes the loop: detect → decide → act
When disease or pest is detected with high confidence, the rover's onboard sprayer (micro-pump + solenoid valve + nozzle) applies a small, targeted dose directly on the affected plant — instead of spraying the entire field. This cuts pesticide use, cost, and chemical exposure while still treating the problem immediately.
